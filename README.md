# beloVET

Сайт ветеринарного врача-хирурга Владислава Белорыбца (Люберцы).

Сейчас прототип на GitHub Pages, закрыт от поисковиков.

## Боевой сайт belovet.ru (хостинг Timeweb)

`node tools/dist.js` собирает боевую версию в `dist/` во временной копии проекта, прототип на GitHub Pages не меняется. По умолчанию без блога и без форм (`BV_BLOG=1`, `BV_FORMS=1` включают их). В `dist/` только публичные файлы и `.htaccess` (https, без www, 404, кэш, сжатие). Содержимое `dist/` выкладывается в корень сайта belovet.ru на Timeweb.

## Запуск на belovet.ru

Всё переключается в начале `tools/build.js`:

- `LAUNCH = true` — адреса в canonical, Open Graph, разметке, sitemap и llms.txt меняются на https://belovet.ru/, снимается `noindex`, `robots.txt` открывается для поисковиков и ИИ-ассистентов, пишется файл `CNAME`, скрывается полоса «Прототип»;
- `METRIKA_ID` — номер счётчика Яндекс Метрики (ставится на все страницы);
- `VERIFY` — коды подтверждения Яндекс Вебмастера и Google Search Console, если подтверждать не через DNS;
- `LEAD_URL` — адрес обработчика форм (см. ниже);
- `OPERATOR` — данные оператора персональных данных для `privacy.html` и `consent.html`. Пока поля пустые, сборка с `LAUNCH = true` останавливается с ошибкой.

После правки: `node tools/build.js`, коммит, пуш.

До переключения:

1. DNS belovet.ru (панель Timeweb → Домены → belovet.ru → DNS): у корня домена заменить A-запись 92.53.96.136 на четыре A-записи 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153; для www — CNAME на antonseliverstov.github.io. MX- и TXT-записи почты (mx1/mx2.timeweb.ru, SPF) не трогать.
2. В настройках репозитория (Settings → Pages) указать домен belovet.ru и включить Enforce HTTPS.
3. Подключить отправку форм — обработчик `functions/lead` (см. ниже) и `LEAD_URL`.
4. Заполнить `OPERATOR` и отдать черновики `privacy.html` и `consent.html` юристу; при отправке заявок в Telegram — уведомить Роскомнадзор о трансграничной передаче.
5. Медицинская вычитка статей врачом.

### Обработчик форм (functions/lead.php)

Заявки с трёх форм (запись, экстренно, вопрос врачу) уходят письмом на vladislav@belovet.ru через PHP-скрипт на том же хостинге Timeweb: данные остаются в России, Telegram и облачные сервисы не используются (решение 10.11.2026; позже — CRM). Пароли не нужны: письмо отправляет mail() хостинга от site@belovet.ru.

Включение: `BV_FORMS=1 node tools/dist.js` — скрипт ляжет в dist/api/lead.php, формы будут отправлять на /api/lead.php. Перед этим — ответ юриста про уведомление Роскомнадзора. После выкладки отправить тестовую заявку и проверить, что письмо пришло не в спам.

Старый вариант для Yandex Cloud Functions (functions/lead/) не используется.

В Метрике при подключённом счётчике срабатывают цели `lead_book`, `lead_ask`, `lead_urgent` (отправка формы) и `phone` (клик по номеру) — их нужно создать в настройках счётчика как JavaScript-события. В настройках Вебвизора отключить запись содержимого полей.

После запуска: добавить сайт в Яндекс Вебмастер и Google Search Console, отправить sitemap.xml, указать регион (Люберцы) в Вебмастере, проверить карточку в Яндекс Бизнесе.

## Структура

- `index.html` — главная страница
- `assets/` — логотипы и фото для сайта (уменьшенные)
- `brand/` — цвета бренда (`colors.css`) и исходники логотипа
- `materials/` — прайс и исходные фото, только локально, в репозиторий не попадает

## Операции и цены

- Все операции, цены, поисковые фразы и тексты страниц — в `data/procedures.js`.
- После правки запустить `node tools/build.js`: он пересоберёт страницы `operations/*.html`, данные поиска `assets/search-data.js`, список категорий на главной (между метками `SURGERY:START/END`) и `sitemap.xml`.
- Страницы и блок на главной вручную не править — изменения сотрёт следующая сборка.

## Формы

Формы записи пока не отправляют заявки (статичный сайт). Обработчик — в конце `index.html`, место отмечено комментарием.
