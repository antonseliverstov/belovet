Кнопка-капсула: оранжевая для главного действия, тёмная для второго, контурная для третьего.

- Классы: `bv-btn` + `bv-btn--primary` | `bv-btn--dark` | `bv-btn--outline`. Нужен `bundle.css`.
- Потребитель даёт текст-глагол и ссылку: «Записаться», «Позвонить», «Прислать снимки».
- `primary` (`orange`) — один раз на экран. Рядом ставится `dark` или `outline`, не вторая оранжевая.
- Высота 52px, текст 17px жирный: белый на `orange` читается только так (3.1:1).
- Фокус — кольцо `blue-text` 3px.
- Не делать: иконки-эмодзи в кнопке, кнопки с градиентом, «Подробнее» без объекта.
