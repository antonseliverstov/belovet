Список цен: название операции по-человечески, уточнение мелким, цена справа.

- Классы: `bv-prices` на `<ul>`, в строке `bv-prices__what` (с `<small>` для уточнения) и `bv-prices__sum`.
- Потребитель даёт строки из утверждённого прайса. Название — понятное владельцу («Удаление камней из мочевого пузыря»), термин можно дать в уточнении.
- Над списком всегда пометка: цена без наркоза, наркоз 3 400 – 13 800 ₽.
- Диапазон пишется через короткое тире с пробелами: «17 250 – 34 500 ₽». Между цифрами и «₽» — неразрывный пробел.
- Не использовать точечные выноски и таблицы с рамками.
