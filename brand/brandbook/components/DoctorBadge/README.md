Бейдж врача: круглое фото, имя и роль в белой капсуле с тенью.

- Классы: `bv-doctor`, внутри `<img>` 56×56 (или `bv-doctor__ph` с инициалами, пока нет фото), `<b>` имя, `<span>` роль.
- Потребитель даёт настоящее фото врача: портрет до пояса, лицо по центру. Нейросетевые портреты не ставить.
- Ставится на первом экране под кнопками и в конце страниц операций.
- Тень `shadow-card` — потому что бейдж лежит поверх большого знака.
