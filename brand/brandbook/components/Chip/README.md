Капсула для короткой справки: адрес, график, срочность, уточнение к цене.

- Классы: `bv-chip`; `bv-chip--urgent` добавляет оранжевую точку; `bv-chip--sky` — для капсулы на белой карточке.
- Потребитель даёт текст до пяти слов. Не кликабельна: для действия есть Button.
- На `sky-soft` — белая капсула, на `paper` — `bv-chip--sky`.
- Точка `--urgent` заменяет оранжевую кнопку только там, где кнопки нет.
