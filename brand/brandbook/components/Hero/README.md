- Классы: `bv-hero`, `bv-hero__mark` (знак), `bv-hero__wordmark` (надпись), `bv-hero__body`; внутри — Button, DoctorBadge.
- Потребитель даёт заголовок до 8 слов с одним выделением `<em>` (цвет `blue`), строку до 15 слов, две кнопки.
- Знак занимает 60–80% высоты и не заходит под текст. На телефоне — под текстом, прозрачность 0.18.
- Фон — `sky-soft`. Оранжевая кнопка на экране одна.
